# 學群探索：四種版本

原始碼在 prototypes/interest-explorer/curiosity/。執行 node tools/sync_explorer_site.js 同步15個資產至 site/explore/；部署前也會同步。此輪僅本機修改，未推送或發布。

## 路線

|版本|流程|
|---|---|
|興趣快速|3輪×6情境 → 最終優先2–3題 → 概覽 → 結果|
|興趣深入|6輪×6情境 → 最終優先2–3題 → 3–4科各3項具體掌握 → 結果|
|能力快速|概覽 → 10題四點興趣（6優勢/4跨領域） → 結果|
|能力深入|概覽 → 15題四點興趣（9優勢/6跨領域） → 3–4科各3項掌握 → 結果|

概覽國英數、社會、自然共十科必填，資訊、生活科技、美術、音樂、體育五科自由選填；可以個別清除或全部略過。兩種自評一律非常糟0、不好1、普通2、好3、非常強4。0是有效回答，null是未填。

興趣篩選每輪六題必須打叉2–3題，完成快速3輪或深入6輪後，才將所有未排除題目重新洗牌；最後均勻分成快速2輪、深入4輪，每輪各勾選2–3題，分頁不額外計輪；快速總計4–6題、深入8–12題。懸停或鍵盤聚焦顯示紅叉／綠勾，整張卡片可點擊選取或取消，手機直接點選。18情境涵蓋18個原始學群，36情境每群2題；概念不重複，單題可連結複數群。這是相對偏好，略過不是完全沒興趣。快速升級保留前18情境及打叉決定，新增3輪，清除最終勾選，待完成新增輪次後重新洗牌確認興趣；能力升級保留前10題及回答，新增3優勢/2跨域題。未完成概覽也可升級，先繼續概覽。

## 計算

篩選版每個實際出現題目為打叉0、保留1、最終勾選3，再依學群相關題目平均，門檻1.5；能力版四點0–3平均，門檻2。此門檻為編輯設定，兩種興趣方法不是等值測量，不用原始選取次數排名。

快速版基礎＝概覽科目分數的學群加權平均。深入版先平均每科3項具體掌握，再依學群權重平均；概覽只配題，不進入深入結果。核心3、支持2、相關1為本站學群規則，不是考招加權。未填科目完全排除分子和分母；同時顯示參考權重覆蓋率（不是適配率）。至少涵蓋50%參考權重且有興趣證據才分類，否則顯示在其他學群。

興趣達門檻且基礎>=3：優先探索；興趣達門檻且基礎<=1：興趣延伸；其餘興趣達門檻：能力培養；興趣低於門檻而基礎>=3：潛力發掘；其他：其他學群。取消pending與概覽/細項矛盾檢查。自評不是實測能力、修課資格或錄取機率，陌生也不等於能力差。

能力配題以已涵蓋至少一半參考權重的概覽群優勢排序；不把少量國文資料推成未評藝術優勢。深入選科優先保留最多2科概覽強項（>=3），再納入高興趣方向，共3–4科。同分依有效概覽與實際情境順序處理。即使強項沒有出現在興趣題，也可使用完整學群對照找任務情境，但不替該群捏造興趣回答。

## 內容與結果介面

保留54道篩選情境與180題教師原始題庫；維持之前9題精簡改寫，原文另存。exploration-model.js提供18群權重、90項課綱連結目標（每科6項）與情境挑選規則。同科依不同群選不同3項任務，仍屬本站編輯規則。引用使用既有51筆課綱資料與ColleGo!參考快照（2026-10-16）；新題文不是官方試題。

結果只有非空分類可切換，一次一類；只有一類時不顯示頁籤。其他學群使用獨立視圖，保留返回推薦。卡片短介紹呈現領域，主按鈕開啟主站精確學群，次按鈕以原生dialog顯示推薦依據。可選最多3群加入本次探索清單。詳細測驗說明由左下來源按鈕開啟。

主站路徑 /explore/curiosity/；學群連結採相對根路徑，支援GitHub Pages專案子路徑。5174/curiosity/開發頁回到5173主站。無後端、localStorage或追蹤；答案只在記憶體，刷新清除；JSON筆記由用戶主動下載。
