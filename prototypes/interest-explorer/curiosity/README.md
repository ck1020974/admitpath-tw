# 學群探索：一個入口

原始碼在 prototypes/interest-explorer/curiosity/。執行 `node tools/sync_explorer_site.js` 同步到 site/explore/；部署時也會自動同步。

2026-10-22 起把原本的四種版本（興趣／能力 × 快速／深入）合併成一條主流程。舊版說明保留在 FOUR_ROUTE_REVIEW.md 與 CONTENT_REVIEW.md。

## 流程

| 步驟 | 內容 |
|---|---|
| 入口 | 18 個圓點、標題、一行說明與「18 題・約 5 分鐘」；有存檔時顯示「繼續上次的探索」與「重新開始」 |
| 1 好奇心 | 18 題（每個學群從 6 題隨機抽 1 題，學群順序固定；同一位學生存檔後題目不變，重新開始會重抽），一頁 6 題、共 3 頁，每題選沒興趣／還好／想知道；整頁答完才能到下一頁，手機會自動捲到下一題 |
| 2 最想知道 | 「想知道」超過 3 題時，從中挑出剛好 3 題；不超過 3 題就跳過 |
| 3 學科表現 | 一個畫面三題，全部必填：整體成績（後段／中間／前段，右邊最好）、最拿手的科目（2–3 科）、比較吃力的科目（2–3 科）；同一科不能兩邊都勾 |
| 結果 | 上排分類頁籤（優先探索、能力培養、興趣延伸、潛力發掘），點選後下方顯示該類學群卡片（相關強項、常見學類、下一步）；符合條件時顯示「也可以考慮：不分系」；其他學群；深入探索、重新測驗 |
| 深入探索（選擇性） | 針對前 4 個方向各補問 3 題（最多 12 題，一頁 6 題），再檢查最相關的最多 4 科、每科 5 項課綱內容（3 項共同核心＋2 項學群方向延伸）；先嘗試同頁顯示五項，實際放不下才分頁 |
| 重新測驗（選擇性） | 每個學群再問 1 題沒看過的題目（一批 18 題）；答完才計入興趣，可以換到題目用完（最多 5 批） |

題庫 108 題、每個學群 6 題（data.js 的 `rows`，題文來自 bank.js 的 180 題草稿）。學群順序在 data.js 的 `quickSet`（題號也是 v4、v5 舊連結的固定題組）。2026-10-28 起已取消結果分享；引擎保留舊版編解碼供相容性測試。

## 計算（本站編輯規則，未經測量驗證）

- 興趣：最想知道 3、想知道 2、還好 1、沒興趣 0。每個學群取相關題目的加權平均，題目所屬學群算 2 倍、跨群連結算 1 倍；達 1.5 視為有興趣。
- 學科：前段＝好 3、中間＝普通 2、後段＝不好 1；勾成強項的科目高一級、吃力的低一級，其餘十科等於整體程度。資訊、生活科技、美術、音樂只有勾選時才計入（2026-10-23 取消體育，遊憩運動改看英文、國文、生物、地理）。依學群科目權重（3／2／1）加權平均。推薦理由的「相關強項」只列學生自己勾的科目。
  - 有基礎：平均 ≥ 2.75，或 ≥ 2 且比自己各科平均高 0.25 以上。
  - 比較吃力：平均 < 1.5 且低於自己的平均。
  - 已評估權重不到一半：不判斷基礎。
- 分類：有興趣＋有基礎＝優先探索；有興趣＋普通＝能力培養；有興趣＋吃力或不判斷＝興趣延伸；沒興趣但有基礎＝潛力發掘（最多 3 個，不列學生選「沒興趣」的學群）；其餘為其他學群。
- 不分系：最想知道的 3 題分屬 3 個不同領域（理工、生醫、設計藝術、人文語言、社會商管），且有興趣的學群橫跨 3 個以上領域；或完全沒有有興趣的學群。模擬約 16–18% 的學生會看到。連結直接打開主站的不分系學類。
- 深入探索完成後，檢查過的科目改用具體內容平均（同樣 0–4），其他科目維持原本的學科感覺，所以不會再發生「最有興趣的學群因科目沒評到而掉到其他」的情況。
- 改了快速題答案、最想知道或學科感覺，深入探索會取消，需要重新確認。

## 存檔與使用統計

- 進度存在瀏覽器 localStorage（`yuhsin-curiosity:v4`，內容為第 7 版，也能讀第 4–6 版存檔），重新整理或關掉再開都會保留；「重新開始」需要按兩次才會清除。
- 已取消分享按鈕、姓名欄位、連結複製與分享結果讀取。匿名施測計次見 `docs/usage-tracking.md`；不集中保存個人完整結果。
- 結果頁的學群與學類連結在同一分頁開啟主站（`?view=explorer&group=…&category=…&from=curiosity`），主站會顯示「回到我的探索結果」。

## 2026-10-28 深入科目題庫

每科保留 10 個課綱改寫項目，共 14 科、140 項；references 指向 curriculum.js 既有條目，保留課綱代碼、條目節錄、PDF 頁碼及來源。這是既有課綱範圍的自評項目，並非整科課綱的完整抽樣。

新版固定 3 項共同核心，再依科目與學群情境選取 2 項延伸。每項等權取平均，完成整輪後才取代該科原本的推估分數；學群權重及門檻未改。舊版三項計畫保留原題及答案，重新儲存與連結往返不會被迫補成五項。新作答使用第 7 版。

題目先以完整五項呈現，依實際可視範圍不足時才分頁，維持完整題文、至少 44px 選項與「繼續」操作；本科作答計數跨頁累計。

額外驗證：`node tools/test_deep_curriculum.js`。
