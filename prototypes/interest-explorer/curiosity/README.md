# 學群探索：一個入口

原始碼在 prototypes/interest-explorer/curiosity/。執行 `node tools/sync_explorer_site.js` 同步到 site/explore/；部署時也會自動同步。

2026-10-22 起把原本的四種版本（興趣／能力 × 快速／深入）合併成一條主流程。舊版說明保留在 FOUR_ROUTE_REVIEW.md 與 CONTENT_REVIEW.md。

## 流程

| 步驟 | 內容 |
|---|---|
| 入口 | 說明三個步驟與時間；有存檔時顯示「繼續上次的探索」與「重新開始」 |
| 1 好奇心 | 固定 18 題（每個學群 1 題），一頁 6 題、共 3 頁，每題選沒興趣／還好／想知道；整頁答完才能到下一頁，手機會自動捲到下一題 |
| 2 最想知道 | 「想知道」超過 3 題時，從中挑出剛好 3 題；不超過 3 題就跳過 |
| 3 學科表現 | 一個畫面三題：整體成績（前段／中間／後段，必填）、最拿手的科目（最多 3 科）、比較吃力的科目（最多 2 科）；同一科不能兩邊都勾 |
| 結果 | 上排分類頁籤（優先探索、能力培養、興趣延伸、潛力發掘），點選後下方顯示該類學群卡片（理由、常見學類、下一步）；其他學群、深入確認、結果連結；最想知道的問題放在頁尾 |
| 深入確認（選擇性） | 針對前 4 個方向補問其餘情境題（最多 8 題，同一頁作答），再檢查最相關的 4 科、每科 3 項課綱內容 |

快速題組在 data.js 的 `quickSet`，全班看到同一組、同一順序。要換題時改題號即可，須每個學群一題。

## 計算（本站編輯規則，未經測量驗證）

- 興趣：最想知道 3、想知道 2、還好 1、沒興趣 0。每個學群取相關題目的加權平均，題目所屬學群算 2 倍、跨群連結算 1 倍；達 1.5 視為有興趣。
- 學科：前段＝好 3、中間＝普通 2、後段＝不好 1；勾成強項的科目高一級、吃力的低一級，其餘十科等於整體程度。資訊、生活科技、美術、音樂、體育只有勾選時才計入。依學群科目權重（3／2／1）加權平均。推薦理由的「相關強項」只列學生自己勾的科目。
  - 有基礎：平均 ≥ 2.75，或 ≥ 2 且比自己各科平均高 0.25 以上。
  - 比較吃力：平均 < 1.5 且低於自己的平均。
  - 已評估權重不到一半：不判斷基礎。
- 分類：有興趣＋有基礎＝優先探索；有興趣＋普通＝能力培養；有興趣＋吃力或不判斷＝興趣延伸；沒興趣但有基礎＝潛力發掘（最多 3 個，不列學生選「沒興趣」的學群）；其餘為其他學群。
- 深入確認完成後，檢查過的科目改用具體內容平均（同樣 0–4），其他科目維持原本的學科感覺，所以不會再發生「最有興趣的學群因科目沒評到而掉到其他」的情況。
- 改了快速題答案、最想知道或學科感覺，深入確認會取消，需要重新確認。

## 存檔與分享

- 進度存在瀏覽器 localStorage（`yuhsin-curiosity:v4`），重新整理或關掉再開都會保留；「重新開始」需要按兩次才會清除。
- 「複製結果連結」把作答壓成約 160 字元的 `#r=` 連結，可附名字或座號（選填，最多 20 字）。打開連結只會顯示那份結果，不會改動自己的作答。
- 結果頁的學群與學類連結在同一分頁開啟主站（`?view=explorer&group=…&category=…&from=curiosity`），主站會顯示「回到我的探索結果」。
