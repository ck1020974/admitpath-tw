# 支持作者收款設定

目前網站功能已設為「尚未開放贊助」，沒有收款連結，不會發起付款。

## 1. 申請個人收款

先從 [綠界官方註冊頁](https://vendor.ecpay.com.tw/User/LogOn_Step1) 及 [快速收款介紹](https://cashier.ecpay.com.tw/intro-quickpay) 了解服務。2026-10-15 核對註冊頁，官方將「直播（斗內）」列入須申請特約賣家的產業；本網站為免費升學工具、接受單次自願支持，是否適用該分類須由綠界確認，不能直接保證可使用一般個人賣家帳號。

在提交收款審核前，請先向綠界確認接受此用途、適用賣家身分與方案，以及個人名義可否申請。不要為通過審核而填寫不符合實況的商品／服務類別。

依核准方案完成本人身分及銀行帳戶驗證。驗證資料只交給金流平台，不要放進 GitHub 或網站設定。

可直接貼給客服的詢問文字：

> 您好，我是一位中學公民科教師，自學程式並製作「YUHSIN 祐馨升學網」（https://ck1020974.github.io/admitpath-tw/），免費提供台灣升學資料查詢。希望以個人名義接受單次、自訂金額的自願贊助，用於資料整理及網站維護；無直播、無付費會員、無訂閱或商品回饋。請問此用途是否受理？適用一般個人賣家或特約賣家？個人可否申請？可使用快速收款連結或哪一種收款工具？需要哪些文件、聯絡資訊及費用？

官方準備資料說明包含手機、電子信箱、身分證件及本人同名台幣帳戶存摺封面等；也可能依審核要求補充環境照片。網站需顯示與會員資料相符的聯絡資訊。請依 [最新官方清單](https://support.ecpay.com.tw/4862/) 及審核人員指示準備。

申請網站網址應填公開網址 `https://ck1020974.github.io/admitpath-tw/`，不可填只有本機能存取的 `http://127.0.0.1:5173/`。送審前請確認正式網站已顯示最新贊助介紹及公開聯絡方式。

申請用途可依實況填寫：

> YUHSIN 祐馨升學網為免費的台灣升學資訊查詢網站，提供招生資料整理與查詢工具。收款用途為支持作者資料整理與網站維護的個人單次自願贊助，沒有付費解鎖或訂閱回饋。

是否受理及可用付款方式以平台審核為準。若審核要求補充網站內容，依平台要求補齊後再啟用。

## 2. 設定平台付款頁

1. 建立單次贊助付款連結，選擇讓付款者填寫金額（以核准功能為準）。
2. 顯示能讓付款者辨識的收款人／網站名稱。
3. 在付款頁設定聯絡及退款處理管道，確認有付款疑問時能聯絡作者。
4. 核對平台公布的手續費、撥款天期及提領規定，確認綁定本人銀行帳戶。
5. 使用平台預覽確認手機與桌面版、金額及顯示名稱；測試交易請依平台測試規則操作。正式交易可能收費，不能假設零成本。

網站不收集卡號、不追蹤實際付款結果，不會因回到本站就顯示付款成功。付款紀錄與交易結果以金流平台為準。

## 3. 啟用網站按鈕

修改 `site/support-config.js`：

```js
window.YUHSIN_SUPPORT_CONFIG = Object.freeze({
  enabled: true,
  paymentUrl: "貼上平台核發的完整 HTTPS 公開收款網址",
});
```

上面的文字是填寫說明，不是真實收款網址。請替換成自己已通過審核且確認收款人正確的網址。

目前允許 `ecpay.com.tw`、`opay.tw` 及其子網域，拒絕其他網域、HTTP、內含帳密及非標準連接埠的網址。域名驗證不能代替人工確認付款頁收款人。若平台核發不同網域，先核對官方來源再調整 `site/support.js` 的允許清單。

不要放入 MerchantID 對應的秘密資料、HashKey、HashIV、信用卡或身分證資料。此功能只使用公開連結。

啟用後請增加 `site/index.html` 中 `support-config.js?v=20261015` 的版本字串，避免瀏覽器仍使用快取的舊設定；修改 JS／CSS 時同樣更新對應版本。

## 4. 上線核對

- 執行 `node tools/test_support_config.js`，並以 `node tools/serve-site.js site 5173` 預覽。
- 支持作者按鈕可開啟視窗；關閉、Escape 及鍵盤操作正常。
- 付款尚未設定、關閉或設定錯誤時，只有停用按鈕。
- 啟用時按鈕開啟正確的正式付款頁，金額在平台填寫，聯絡／退款管道清楚。
- 收入、手續費及網站支出紀錄需保留，所得及發票義務依實際經營情況向國稅局或會計師確認，不應承諾公益抵稅收據。

參考：[綠界費率](https://www.ecpay.com.tw/Business/payment_fees?type=s)、[綠界收據類型](https://support.ecpay.com.tw/30204/)。

發布依專案既有 GitHub Pages 流程，合併並推送至 main 後會觸發部署；請確認部署成功，再以正式網址檢查頁面。

## 暫停收款

把 `enabled` 改成 `false`，更新設定檔版本並重新部署；網站會恢復準備中狀態。已開啟或已分享的平台連結需另外在金流後台關閉，網站停用不會撤銷平台連結或取消交易。
